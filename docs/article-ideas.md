# 記事の案（2026-09-26作成）

検索で評価されやすいように、**すでに記事があるテーマ（充電・ストレージ・AI）を優先**して並べています。
各テーマで関連する記事どうしをリンクでつなぐと、「このサイトはこの分野に詳しい」と伝わりやすくなります。

## 使い方
ChatGPT に指示書（docs/chatgpt-brief.md、AIは docs/chatgpt-ai-brief.md）を貼ったあと、最後の「記事のテーマ」に次のように書きます。

```
記事のテーマ：〇〇（下の表のタイトル案）
狙う検索キーワード：〇〇
関連記事（本文から自然にリンクする）：https://ochanote.com/articles/〇〇/
記事の種類：選び方 ／ 比較 ／ 解説 など
```

- 「優先」の★が多いものから書くのがおすすめです。
- 「体験」の欄に ◎ がある案は、実際に使った感想や自分で撮った写真があると記事の価値が大きく上がります。手元にあるものから選んでください。
- 公開済みの記事は `/articles/` のあとに書いたスラッグ（URLの末尾）です。
