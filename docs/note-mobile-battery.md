こんにちは。大学生ガジェット紹介の【ニックネーム】です。

「スマホの充電が夕方までもたない」「カフェでレポートを書いていたらPCの電池が切れそう」。そんなときに頼りになるのがモバイルバッテリーです。
【例：私も1限から5限まである日は、帰りの電車でスマホの残量が10％を切ることがよくあります。】

ただ、「とりあえず大容量を買えば安心」と考えると、重すぎて結局持ち歩かなくなることも。
今回は、大学生がよく使う場面ごとに、どんなモバイルバッテリーを選べばいいかを整理しました。

# 結論：まず「何を充電したいか」で決める

先に答えを書くと、目安はこうなります。

- **スマホを少し足せればいい** → 5,000mAh前後（軽さ優先）
- **通学中にスマホを1日使う** → 10,000mAh前後、USB-C出力20W級
- **ノートPCも充電したい** → 20,000mAh前後から。ただしPC側の条件を必ず確認
- **旅行でスマホを何台も** → 20,000mAh前後。重さとの相談

大学生の多くは、**10,000mAh前後でUSB-C対応のもの**から考えるとちょうどいいと思います。

# 選ぶときに見る3つのポイント

## 1. mAh（容量）だけで回数を計算しない

「10,000mAhなら、5,000mAhのスマホを2回充電できる」と思いがちですが、実際はそれより少なくなります。
バッテリーの中の電気をスマホに送るときに、どうしても損失が出るからです。

何回充電できるかは製品と使い方で変わるので、メーカーが「〇〇の機種で約〇回」と書いている表示を目安にしましょう。

## 2. W（ワット）は「充電の速さ」

mAhが「ためておける量」なら、Wは「送り出す速さ」です。
スマホの急速充電なら、USB-Cの出力が**20W級**あるかがひとつの目安になります。

ノートPCに使いたい人は、ここが一番大事です。

- PCが **USB-Cで充電できる機種か**
- PCのメーカーが推奨している **W数**
- バッテリーの **USB-C 1つだけで出せるW数**

この3つを見比べてください。
「合計65W」と書いてあっても、スマホとPCを同時につなぐと、PCには65W出ないことがあります。

## 3. 重さと、本体を充電する速さ

毎日カバンに入れるなら、重さはかなり大事です。カタログの重量を見て、スマホや財布と一緒に持つイメージをしてみてください。
【例：私は以前、大容量タイプを買って、重くて家に置きっぱなしになりました。】

もう一つ見落としやすいのが、**バッテリー本体への入力（W数）**です。ここが小さいと、夜のうちに満充電にならないことがあります。

# 帰省・旅行の前に：飛行機の新しいルール

年末年始の帰省や旅行で飛行機に乗る人は要注意です。
2026年4月24日から、日本を出発・到着する便（国内線・国際線）で、モバイルバッテリーの扱いが変わりました。

- **預け入れ荷物には入れられない**（機内持ち込みのみ）
- **160Wh以下のものを、1人2個まで**
- **機内では使えない**（スマホへの充電も、バッテリー自体の充電もNG）

容量の「mAh」ではなく、本体に書かれた「**Wh**」で判断します。大容量タイプを買う前に、本体の表示と航空会社の案内を確認しておきましょう。

# 安全のためにチェックしたいこと

- 本体に **PSEマーク** と事業者名があるか
- 販売元の連絡先や保証がはっきりしているか
- 夏の車内など、暑い場所に置きっぱなしにしない
- **膨らむ、いつもより熱い**などの異常があれば、すぐに使うのをやめる
- 捨てるときは普通ごみに混ぜず、自治体やメーカーの回収方法を確認する

値段の安さだけで選ばないことが、いちばんの安全対策です。
