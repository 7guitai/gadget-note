# サムネイル制作プロンプト

Claude Code などに記事のサムネイル（表紙）を作ってもらうときに使う依頼文。【ここにテーマを記入】を書き換えて貼り付ける。
このリポジトリでは、元ファイル（SVG）を design/thumbnails/<slug>.svg に置き、`node scripts/export-thumbnail.mjs <slug>` でPNGと記事用の画像を書き出す（手順は design/README.md）。

---ここから---

記事のサムネイルを、SVGまたはHTML/CSSで制作してください。画像生成APIや有料サービスは使わず、完成したPNG画像まで書き出してください。

【対象】
サイト：OCHA NOTE
読者：大学生
記事テーマ：【ここにテーマを記入】
記事本文や既存ファイルがある場合は、内容を読んでから制作してください。

【デザイン】
・サイズは1200×630px。
・抹茶色、アイボリー、淡いグレーを基調に、かわいさと読みやすさを両立する。
・余白を広めに取り、雑誌の表紙のように整える。
・テーマに合うイラストをSVGの図形やパスで描く。図形を散りばめるだけでなく、記事の内容が伝わるモチーフにする。
・見出しは短い日本語で、最大2行。スマホの小さな表示でも読める大きさにする。
・「OCHA NOTE」を小さく添える。
・要素を詰め込みすぎず、強いグラデーションや過度な影は避ける。
・実在の商品を描く場合、未確認の形状・ロゴ・仕様を創作しない。資料がない場合は一般的なイラストにする。
・日本語対応フォントを使用し、文字化けや意図しないフォントへの置き換わりを確認する。

【制作手順】

1. プロジェクトの構成と既存サムネを確認し、保存先とサイトの雰囲気を把握する。
2. 編集可能なSVG、またはHTML/CSSの元ファイルを作る。
3. 既存のツールを優先し、必要に応じてPlaywrightなどで1200×630pxのPNGを書き出す。HTMLの場合は、フォントの読み込み完了後にサムネ部分だけを撮影する。
4. 書き出した画像を開き、文字の欠け・重なり・余白・イラストの見やすさを確認して修正する。
5. 元ファイルとPNGを、内容が分かるファイル名で保存する。

この依頼ではサムネ制作と保存まで行ってください。完了時は、保存先と画像プレビューを提示してください。書き出しや画像確認ができなかった場合は、その状態を明記してください。
