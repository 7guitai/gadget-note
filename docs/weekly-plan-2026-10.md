# OCHA NOTE 週次プラン（2026年10月5日〜11月1日）

ChatGPT にこのファイルをそのまま貼り付けて共有する。記事を頼むときは、該当する指示書（ガジェット等は docs/chatgpt-brief.md、AIは docs/chatgpt-ai-brief.md）を先に貼り、そのあとに各記事の「依頼文」を貼る。

## 前提（2026年10月1日時点）
- サイト：OCHA NOTE（https://ochanote.com）。「毎日使うものを、ひと息ついて選ぶ」がテーマの選び方メディア。
- 公開済み：20本（ガジェット19本、AI 1本）。充電・ケーブル系が8本、ストレージ系が5本、デスク周り3本、iPad・ミニPC・イヤホン各1本。
- お土産・家具・インテリア・道具箱・暮らしのカテゴリは記事0本のため、メニューに表示していない。1本目が公開されると表示される。
- 運営者は「Gadget｜大学生ガジェット紹介」というnoteアカウントも持っている。サイトは一般の読者向け、noteは大学生向けと分けている。
- 守るルール：使っていないものを「使った」と書かない。仕様と価格は公式で確認し、確認日を書く。根拠のないランキングや「最強」などの言葉を使わない。セール価格や開催日を推測で書かない。

## このプランの方針
1. **週3本**のサイト記事と、**週1本**のnote投稿を基本にする。
2. すでに記事が多い「充電」「ストレージ」は増やしすぎず、記事が少ない **AI・イヤホン・PC・デスク周り** を育てる。
3. 10月中に **家具・インテリア** と **道具箱** の1本目を出し、カテゴリを開く。
4. 体験が必要な記事（◎）は、運営者が写真や感想を用意できる週に回す。用意できなければ、同じ週の別の記事と入れ替える。

## 週の流れ
| 曜日 | やること |
|---|---|
| 月 | Search Consoleで先週の表示回数・クリック数を確認。順位が11〜20位の記事を1本選んで、足りない内容をメモする |
| 火 | 記事1本目を公開 |
| 木 | 記事2本目を公開 |
| 土 | 記事3本目を公開。noteを1本投稿 |
| 日 | 次週の記事の下書きを ChatGPT で作成。体験◎の記事の写真を撮る |

公開した記事は、その日のうちに Search Console の「URL 検査」でインデックス登録をリクエストする。

## 予定が崩れたとき
- 体験◎の記事が用意できない週は、体験なしの記事を先にする。
- 1週間に3本書けない場合は、優先1の記事だけを出す。本数より、事実確認を優先する。
- 新しい製品やサービスの発表があっても、うわさや未確認の情報は書かない。公式発表を確認できたものだけ、AIカテゴリの記事として追加する。
