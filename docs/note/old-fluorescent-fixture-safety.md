# 「LEDランプに替えればずっと使える」は間違い？10年超えの蛍光灯器具に気をつけて

蛍光ランプは、水俣条約によって、一般照明用の製造と輸出入が2027年末までに終わることになっています。そろそろLEDに替えようかな、と考えている人も多いのではないでしょうか。

そのときに気をつけたいのが、照明器具そのものの寿命です。NITE（製品評価技術基盤機構）の注意喚起をもとにまとめました。

## 器具の中には「電気部品」が入っている

蛍光灯器具は、ランプを付ける台ではなく、安定器や配線などの電気部品が入った電気製品です。見た目がきれいでも、長く使うと中の部品が劣化して、発煙や発火につながるおそれがあります。

- 2016〜2025年の10年間に、蛍光灯器具の事故は205件
- 使用年数がわかった事故のうち、約9割が10年超え
- ランプだけLEDに替えた器具の事故も、毎年起きている

## 交換時期の目安

- 8〜10年：適正交換時期
- 15年：耐用の限度

（日本照明工業会の目安として、NITEが紹介しています）

製造年は、器具に貼られた銘板で確認できます。10年を超えていたら、ランプだけでなく、器具ごとLED照明に替えることを考えましょう。

## こんなときはすぐに使うのをやめる

- ちらつく
- 異音がする
- 焦げたにおいがする

気づいたら、すぐに電源を切ってください。

古い蛍光ランプには水銀が含まれているので、捨てるときは自治体のルールに従いましょう。年末の大掃除のついでに、照明の製造年を一度見てみてはいかがでしょうか。
