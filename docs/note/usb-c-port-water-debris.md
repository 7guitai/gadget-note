# 充電口に水・ゴミが入ったら危ない？USB-Cのショートを防ぐ3つの注意

スマホやタブレット、ノートパソコンの充電口。水やゴミ、金属片が入ったまま充電すると、ショートして発煙・焼損するおそれがあります。NITE（製品評価技術基盤機構）の注意喚起とAppleのサポート情報をもとにまとめました。

## なぜ危ないのか

USB-Cの中には24本のピンが並んでいて、すき間がせまいため、異物が入ったまま充電するとショートしやすいと言われています。NITEは、学校のノートパソコンの充電口に異物が入れられて本体が溶けた火災や、落としたタブレットから火が出た事故を紹介しています。

## 気をつける3つのポイント

1. 充電口に水やゴミを入れない。入ったら使うのをやめて相談する
2. 曲がった・壊れた充電口やケーブルは使わない。手で直しても中は変形したままのことがある
3. 落とさない。ケースに入れて持ち歩く。落としたあとに熱・煙・膨らみがあれば使わない

## iPhoneで「液体が検出されました」と出たら

- ケーブルを外し、コネクターを下にして優しくたたいて水分を出す
- 風通しのよい場所で自然乾燥。30分以上たってから充電を試す
- また出たら丸一日置く（最長24時間かかることも）
- ドライヤーなどの熱、エアダスター、綿棒、米の袋はNG
