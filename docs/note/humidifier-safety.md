# 加湿器の蒸気は90℃超えも。子どものやけど・水あかの発火を防ぐ5つの注意

乾燥する季節に活躍する加湿器。スチーム式の熱い蒸気や、倒れてこぼれたお湯で子どもがやけどをしたり、水あかが原因で発火したりする事故が起きています。NITE（製品評価技術基盤機構）の注意喚起をもとにまとめました。

## スチーム式は特に注意

加湿器には、スチーム式（加熱式）、超音波式、気化式があり、ヒーターを組み合わせたハイブリッド式もあります。水を温めるタイプは、熱い蒸気やお湯に注意が必要です。

- NITEの測定では、スチーム式の蒸気の吹き出し口で約90℃を超えるものも
- 倒す試験では、約80℃のお湯がこぼれ出た
- 被害者の年齢がわかった事故15件のうち、7件が10歳未満（1歳と1歳未満が多い）

## 5つの注意

1. 熱いお湯や蒸気を使う製品は、子どもの手が届かず、倒れにくい場所に置く。コードの取り回しにも注意
2. タンクには水道水だけ。アロマなどは説明書で使えると書かれていなければ入れない。満水ラインを超えない
3. 毎日水を替え、水あかを定期的に手入れする。本体は丸洗いしない
4. 電源コードを引っ張ったり、本体にきつく巻き付けたりしない
5. リコールの対象でないか確認する
