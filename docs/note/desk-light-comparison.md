# デスクライトはどう選ぶ？モニターライト・クランプ式・台座式の違い

在宅ワークや勉強で、手元が暗いと感じていませんか。デスクライトは種類が多くて迷いますが、「何の作業をするか」と「机にどう付けるか」で考えると選びやすくなります。

メーカーの公式仕様をもとに、タイプの違う3つの製品を比べてみました（実際に使ったレビューではありません）。

## まずは明るさの目安

厚生労働省のガイドラインでは、パソコン作業のときの書類やキーボードの上の明るさを、300ルクス以上を目安にしています。画面と周りの明るさの差は、なるべく小さくするのがよいそうです。

## パソコン作業が中心なら：モニターライト

BenQの「ScreenBar」は、モニターの上に引っ掛けて使うバー型のライトです。

- 机の上に台座やアームを置かないので、机を広く使える
- 500ルクスで60cm×30cmの範囲を照らす（公式ページより）
- 画面への映り込みを減らす光学設計
- 周りの明るさに合わせて自動で調光
- 光の色は2,700K〜6,500Kの8段階
- パソコンやモニターのUSB端子から給電

照らす範囲は手前に限られるので、大きな紙の資料を広げる人は、ほかのタイプも比べてみてください。

## 広く明るく照らしたいなら：クランプ式

山田照明の「Z-LIGHT Z-10G」は、机の天板のふちにクランプで固定するアーム式のライトです。

- 明るさはJIS AA形相当（公式ページより）
- 横幅400mmのシェードで、机の上を広く照らす
- 光源が目に入りにくい構造
- クランプで付けられる天板の厚さは45mmまで

## クランプを付けられない机なら：台座式

同じく山田照明の「Z-LIGHT Z-6700 B」は、台座で机に置くタイプです。

- 明るさはJIS A形相当（4,200Kのとき）
- 光の色を2,700K・3,500K・4,200K・5,000Kの4段階で切り替えられる
- 夜は暖かい色、作業は白っぽい色、と使い分けたい人に

## 迷ったときは

1. 画面を見る作業が中心で、机を広く使いたい → モニターライト
2. 紙の資料や本も広げて、天板にクランプを付けられる → クランプ式
3. クランプを付けられない、光の色も変えたい → 台座式
