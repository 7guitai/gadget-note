# Androidスマホの「空き容量が少なくなっています」。消す前に確認したい順番

写真や動画を撮っていたら、いつの間にかスマホの容量がいっぱいに…ということ、ありますよね。

GoogleのAndroidヘルプをもとに、空き容量を増やす方法と、大事なデータを消してしまわないための順番をまとめました。

## まずは何が容量を使っているか確認

「設定」→「ストレージ」を開くと、写真や動画、アプリなど、カテゴリごとにどれくらい使っているかが分かります。闇雲に消す前に、ここを見るのがおすすめです。

## 空き容量を増やす5つの方法

1. バックアップ済みの写真や動画を消す
2. ダウンロードした動画や音楽を消す
3. 使っていないアプリをアンインストールする
4. アプリのキャッシュを消す
5. ファイルをパソコンに移してから消す

## 自動で消してくれる「スマートストレージ」

「設定」→「ストレージ」→「空き容量を増やす」のメニューから、「スマート ストレージ」をオンにすると、空き容量が少なくなったときに、バックアップ済みの写真や動画を自動で削除してくれます。

## 気をつけたいこと

- 写真や動画は、Googleフォトなどにバックアップされていることを確かめてから消す
- アプリの「ストレージを消去」は、そのアプリのデータがすべて完全に消えるので慎重に
- キャッシュを消すと、次にアプリを開いたときに少し遅くなることがある
- 使っていないアプリは、アンインストールしても後でもう一度ダウンロードできる（購入済みなら買い直し不要）

メーカーや機種によって、画面の表示が違う場合があります。
