# 冬の料理中に気をつけたい「着衣着火」。ガスこんろの事故を防ぐ4つのポイント

寒くなって、ふわふわのセーターやフリースを着て料理をする季節になりました。実はこの時期、ガスこんろの炎が服に燃え移る「着衣着火」に注意が必要です。

NITE（製品評価技術基盤機構）の注意喚起をもとに、ガスこんろの事故を防ぐポイントをまとめました。

## 炎は見えている部分より広い

NITEによると、ガスこんろの炎は、目に見えている部分の外側にも広がっています。見えている炎から離れていても、服に火がつくおそれがあるそうです。

冬は重ね着で服が厚くなり、服が熱くなっても気付きにくくなります。毛羽立った服に火がつくと、表面を炎が一気に広がることもあります。

NITEが紹介している消防庁のデータでは、着衣着火で毎年100人前後が亡くなっていて、「たき火」の次に「炊事中」の事故が多いとのことです。

## 4つのポイント

1. 衣服と炎の距離を意識して、近づき過ぎない
2. 使っているとき・使った後は点火と消火を確認し、離れるときは必ず火を消す
3. こんろやグリルの汚れを放置しない
4. ペットがいる家では、出かけるときに元栓を閉めて操作ボタンをロックする

## 着衣着火を防ぐためにできること

- 鍋の大きさに合わせて火力を調節し、鍋底から炎がはみ出さないようにする
- こんろの奥に物を置かない。奥の物を取るときは火を消してから
- マフラーなど垂れ下がるものは外す
- 袖や裾が広がった服、毛羽立った服はできるだけ避ける
- エプロンやアームカバーで袖・裾を押さえる

65歳以上の人の死亡事故が多いことや、白内障が進むと青い炎が見えにくくなることにも注意が呼びかけられています。家族で共有しておきたいですね。

## ペットの「もふもふプッシュ」にも注意

ペットがこんろの操作ボタンを押して火がつき、火災になった事故も起きています。NITEはこれを「もふもふプッシュ」と呼んでいます。

出かけるときは元栓を閉め、ボタンのロック機能があれば使いましょう。こんろの近くに、ペットの気を引くものを置かないことも大切です。
