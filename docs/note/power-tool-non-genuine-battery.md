# 電動工具や掃除機の「互換バッテリー」、安いけど大丈夫？充電中の発火事故が多いそうです

電動ドライバーや充電式の掃除機のバッテリーがへたってきたとき、ネット通販で「互換バッテリー」「純正充電器対応」と書かれた安い商品を見かけることがありますよね。

NITE（製品評価技術基盤機構）は、こうした非純正バッテリーの火災事故について注意を呼びかけています（2024年6月発表）。ポイントをまとめました。

## どんな事故が起きている？

2014〜2023年の10年間で、非純正バッテリーによる事故は235件。

- 多いのは、充電式電動工具（103件）と充電式掃除機（97件）
- ほとんどが火災で、建物が全焼した火災も14件
- 約8割が充電中に起きている
- 半数以上が、使い始めて1年未満

買って初めて充電していたら出火した、という例もあります。

## 非純正バッテリーのリスク

- 設計に問題があり、異常のときに安全装置が働かないことがある
- 品質管理が不十分なことがある
- 事故が起きても、販売元にも本体のメーカーにも補償してもらえないことがある

## 買う前・使う前に見たいこと

- 事業者名や連絡先が書かれているか
- 日本語が不自然ではないか
- PSEマークが正しく表示されているか
- 使っている機器のメーカーが、非純正品について注意を出していないか
- リコールの対象になっていないか（消費者庁のリコール情報サイトで検索できる）

いちばん安心なのは、機器本体のメーカーの純正バッテリーを選ぶことです。
