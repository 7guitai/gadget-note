# モバイルバッテリーは飛行機に何個まで？2026年4月から変わった3つのルール

2026年4月24日から、日本の飛行機でのモバイルバッテリーのルールが変わりました。

旅行や出張でいつも持ち歩いている人も多いと思うので、国土交通省の案内をもとに、変わった点と出発前に確認したいことをまとめました。

## 新しく加わった3つのルール

- 機内に持ち込めるのは、160Wh以下のものを2個まで
- 機内で、モバイルバッテリーそのものを充電しない
- 機内で、モバイルバッテリーからスマホなどを充電しない

これまでのルールに、この3つが加わりました。スマホを機内で充電したいときは、座席などに備え付けの電源を使うよう案内されています。

背景には、機内でモバイルバッテリーが発煙・発火する事例が国内外で起きていることがあり、国際基準が緊急で改訂されたそうです。

## もともとのルールも確認

- スーツケースに入れて預けることはできない。必ず機内に持ち込む
- 160Whを超えるものは持ち込めない
- 端子に絶縁テープを貼る、ケースや袋に入れるなど、1個ずつショート対策をする
- 座席の上の収納棚には入れず、座席ポケットなど手元に置く

これらに違反すると、航空法で罰則が科される可能性があります。航空会社によっては、もっと厳しいルールを設けている場合もあるので、乗る便の案内も見ておくと安心です。

## 「160Wh」はどうやって確かめる？

モバイルバッテリーの容量は「mAh」で書かれていることが多いですが、飛行機のルールは「Wh（ワット時）」で決まっています。

計算方法は、

Wh ＝ 定格容量（mAh）× 定格電圧（V）÷ 1,000

国土交通省の例では、27,000mAh・3.7Vのモバイルバッテリーは、27,000×3.7÷1,000＝99.9Wh になります。

本体にWhが書いてあれば、その数字を見ればOKです。

## カメラの予備バッテリーも持っていく人は

カメラの予備バッテリーなどは「予備の電池」として別に数えます。100Whを超える大きめの予備の電池は、持っていくモバイルバッテリーの組み合わせによって、2個まで・1個まで・持ち込み不可と変わります。たくさん持っていく人は、出発前に確認しておきましょう。

## 出発前のチェック

1. スーツケースに入っていないか
2. 1個ずつ160Wh以下で、全部で2個以内か
3. ショート対策をしたか
4. 機内では手元に置き、使わない・充電しない
