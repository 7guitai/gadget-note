# 旅先のお土産をクール便で送る前に。「予冷」をしないと受け付けてもらえません

旅先で買った海産物やお肉、冷凍のスイーツ。持って帰るのは大変なので、クール便で送りたいですよね。

ヤマト運輸の「クール宅急便」の公式ページをもとに、送る前に確認したいことをまとめました。

## 冷蔵と冷凍の2タイプ

- 冷蔵タイプ：0〜10℃（予冷の目安は10℃以下で6時間以上）
- 冷凍タイプ：-15℃（予冷の目安は-15℃以下で12時間以上）

## いちばん大事なのは「予冷」

クール宅急便は、温度を「保つ」サービスで、荷物を冷やしたり凍らせたりする機能はありません。予冷していない荷物は、ほかの人の荷物にも影響するため、受け付けてもらえません。

旅先で買ってすぐ送りたいときは、お店から冷えた状態で発送してもらえるか確認すると安心です。

## ほかにも確認したいこと

- サイズは120サイズ（120cm・15kg）まで
- 送れるのは、ヤマト運輸の営業所への持ち込みか集荷だけ。コンビニからは送れない
- アイスクリームは、発泡スチロールの容器と十分なドライアイスが必要（60サイズの容器に2kgが目安）
- 品名は「雑貨」などではなく、具体的に書く
- 受け取る人が不在だと、営業所で保管されるのは最大3日間

宅急便の運賃に加えて、クールのオプション料金（60サイズで275円〜、税込、11月14日確認）がかかります。

旅行の前に、近くの営業所の場所も調べておくとスムーズです。
