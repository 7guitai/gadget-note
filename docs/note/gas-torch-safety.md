# ガストーチの事故は7割が製品の不具合。PSLPGマークの確認とガス漏れを防ぐ使い方

あぶり料理やキャンプの火起こしに便利なガストーチ（ガスバーナー）。粗悪な製品のガス漏れによる火災が多く起きています。NITE（製品評価技術基盤機構）の注意喚起をもとにまとめました。

## 事故の状況

- 5年間で129件、そのうち121件が火災
- 原因を調べ終えた事故の約7割が、製品の不具合に関係
- いちばん多いのは、Oリング（接続部のゴムパッキン）の不具合によるガス漏れ
- 不具合が関係する事故の多くは、ネットで買った海外製の製品

## 買うときは

- ひし形の「PSLPGマーク」があるか（2025年2月からガストーチも規制の対象に）
- 国内の連絡先、指定のカセットボンベ、日本語の取扱説明書があるか

## 使うときは

1. ボンベを付ける前に、接続部やバーナーに異物がないか確認
2. 火の元から離れて付け、「シュー」という音やガスのにおいがしないか確認
3. 点火はボンベを立てた状態で。使用中に傾けるのは45度までを目安に

リコール対象になっていないかも確認しておきましょう。
