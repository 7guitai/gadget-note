# ACアダプターの使い回しは発火の危険。形が同じでも電圧は別

家にあるACアダプター（充電器）、プラグの形が合うからと別の製品に使っていませんか。NITE（製品評価技術基盤機構）は、ほかの製品のACアダプターで充電して発火した事故について注意を呼びかけています。

## なぜ危ないのか

ACアダプターは製品ごとに充電の条件などが違います。特に、付属品より出力電圧の高いACアダプターにつなぐと、中のリチウムイオン電池が過充電になって、発火や破裂につながるおそれがあります。

- 充電式ライトの事故は5年間で50件、そのうち41件が充電中
- 原因がわかった11件のうち7件で、別の製品のACアダプターを使っていた
- 掃除機でも、他社のACアダプターで充電中に発火した事故が10件

## 取り違えを防ぐには

- 充電は製品に付属のACアダプターで行う
- どの機器用か、ラベルを貼って区別する
- 防災用のライトは、慌てて取り違えないよう、ふだんから充電しておく
- 充電中はその場を離れず、燃えやすい物のない場所で充電する
