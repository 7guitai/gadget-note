# Googleのパスキーとは？パスワードなしでログインする設定方法

Googleアカウントに「パスキー」を設定すると、パスワードの代わりに、スマホの指紋認証や顔認証、画面ロックのPINでログインできます。Google アカウント ヘルプをもとにまとめました。

## パスキーのいいところ

- パスワードと違って人に教えたり書き留めたりできないので、フィッシングに強い
- パスワードを覚えて入力しなくてよい
- 指紋や顔のデータは端末の中に保存され、Googleには送られない

## 作り方

1. myaccount.google.com/signinoptions/passkeys を開く
2. 「パスキーを作成」をタップ
3. 端末のロックを解除する

事前に、スマホの画面ロックをオンに。iPhone・iPad・MacではiCloudキーチェーンをオンにしておきます。

## 知っておきたいこと

- 家族や職場の共有の端末では作らない
- 作ったばかりのパスキーは、使えるまで7日間ほどかかる場合がある
- パソコンでは、表示されたQRコードをスマホで読み取ってログインできる
- スマホをなくしたら、別の端末から「セキュリティとログイン」でパスキーを削除する
