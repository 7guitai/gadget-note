# Geminiに「配車して」「ピザを頼んで」が日本でも。便利だけど、任せる前に知っておきたいこと

Googleが11月11日に発表した「11月の Pixel Drop」で、Geminiに特定のアプリを使った日常のタスクを任せられる機能が、日本でも使えるようになりました。

Googleのヘルプでは「スクリーン オートメーション」と呼ばれている、Geminiアプリのベータ版の機能です。公式のブログとヘルプをもとに、使える条件と、気をつけたい点をまとめました。

## どんなことができる？

Geminiが、スマホの中に用意した仮想の画面でアプリを開き、タップや入力をしながら作業を進めてくれます。ヘルプでは、こんな頼み方が例に挙がっています。

- 「空港までの配車を予約して」
- 「前回注文したコーヒーを再注文して」
- 「カートに牛乳と卵を追加して」

ただし、使えるのは「一部のアプリ」で、日本で対応しているアプリの一覧は、確認した公式ページには載っていませんでした。

## 使える条件

- 機種：Google Pixel 10・11シリーズ（ヘルプにはGalaxy S26シリーズなども記載）
- 18歳以上で、個人のGoogleアカウント（仕事用・学校用は不可）
- 言語：日本語・英語・韓国語
- 段階的に提供中なので、まだ出てこない人もいる

## 使い方の流れ

1. Geminiアプリで「〇〇を予約して」と頼む
2. 初めてのときは、スクリーン オートメーションの使用を許可する
3. Geminiが作った進め方（アクションプラン）を確認する
4. 注文の確定など、最後のステップは自分で行う

途中経過は「進行状況を表示」で見られて、「タスクを停止」でいつでも止められます。

## 任せる前に知っておきたいこと

Googleはヘルプで、リスクについてもかなり詳しく書いています。

- Geminiは、違うボタンを押したり、数量を間違えたりすることがある
- Geminiの操作で起きた予期しない購入などは、利用者の責任になる
- 緊急の用事や、機密情報が関わる作業には使わない
- ログイン情報や支払いの情報は、チャットに直接入力しない
- ウェブやアプリに仕込まれた悪意のある指示（プロンプトインジェクション）で、だまされるおそれがある

いちばん大事なのは「見守ること」だそうです。最初は、アプリごとの許可を「毎回確認」にしておき、間違えても困らない作業から試すのがよさそうです。注文の準備だけで止めたときは、カートに商品が残っていないかも確認しておきましょう。
