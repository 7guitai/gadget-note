# 留守中のペットが火事に？犬・猫の「こんろ押し」と尿の発火を防ぐ5つの対策

犬や猫がこんろのボタンを押したり、電気製品におしっこをかけたり、コードをかんだりして起きる火災があります。NITE（製品評価技術基盤機構）の注意喚起をもとにまとめました。

## 事故の約9割が火災

NITEによると、ペットが関係した製品事故は10年間で61件、そのうち54件が火災でした。多かったのは次のような事故です。

- こんろのボタンやスイッチを押して発火（27件）
- 尿や水分のついた抜け毛によるトラッキング現象で発火（19件）
- 配線器具やバッテリーをかんでショートし発火（10件）

猫は高い所に飛び乗って、IHこんろやプリンターなどで事故を起こすことも。犬はコードやバッテリーをかむことがあります。

## 出かける前の5つの対策

1. ガスこんろは元栓を閉め、IH・電気こんろは主電源を切る。ボタンのロックがあれば使う
2. 目を離すときはペットをケージに入れる
3. こんろや暖房器具のまわりに燃えやすい物やえさ・おもちゃを置かない。IHの上に金属のボウルを置きっぱなしにしない
4. 使わない電気製品はプラグを抜き、届かない場所にしまう
5. ペットがおしっこをしがちな場所に延長コードや電気製品を置かない
