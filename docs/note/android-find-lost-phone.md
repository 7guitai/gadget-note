# Androidスマホをなくした！そのとき慌てないために、今のうちに確認したい設定

スマホが見当たらないと、本当に焦りますよね。Androidスマホなら、Googleの「Find Hub」で場所を調べたり、音を鳴らしたりできます。

GoogleのAndroidヘルプをもとに、なくしたときの探し方と、なくす前にしておきたい設定をまとめました。

## なくしたときは、まずFind Hubを開く

- 別のAndroidスマホやタブレットがあれば、Find Hubアプリを開く
- なければ、パソコンなどのブラウザで android.com/find にアクセス
- 家族や友だちのAndroidを借りるときは、「ゲストとしてログイン」で自分のアカウントに入る

地図に、スマホの今の場所（わからなければ最後に確認された場所）が表示されます。

## できること

- 音を鳴らす：最大音量で5分間。マナーモードでも鳴る
- 付近を探す：10メートル以内なら、近づくほど画面の図形に色がつく
- 紛失としてマーク：スマホをロックして、ロック画面に連絡先とメッセージを表示できる
- データを消去：最後の手段。消すとFind Hubで探せなくなり、SDカードのデータは残る場合もある

## なくす前に確認しておきたいこと

- Googleアカウントにログインしている
- 位置情報がオンになっている
- 「設定」→「セキュリティ」→「Find Hub」で、場所の特定が許可されている
- 「オフラインのデバイスを探す」を設定している
- 画面ロック（PIN・パターン・パスワード）を設定している

「オフラインのデバイスを探す」は、ネットにつながっていないスマホでも、近くにあるほかの人のAndroid端末を通じて場所を探せる仕組みです。Pixel 8シリーズなどの対応機種なら、電源が切れても数時間は探せるそうです。

## 意外と大事な「バックアップコード」

なくしたスマホが、Googleアカウントにログインするときの確認コードを受け取る端末になっていると、パソコンからログインできずに困ることがあります。2段階認証を使っている人は、バックアップコードを作って、スマホとは別の場所に保管しておきましょう。

一度、android.com/find を開いて、自分のスマホが表示されるか試しておくと安心です。
