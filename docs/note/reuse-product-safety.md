# 中古家電・もらい物の事故、9割は火災。使う前の5つのチェック

フリマアプリで買った家電、知人から譲ってもらった製品、中古住宅にもともと付いていたエアコン。こうした「リユース品」で、火災事故が起きています。

NITE（製品評価技術基盤機構）によると、2020〜2024年の5年間にリユース品の事故は310件あり、約9割が火災でした。NITEの注意喚起をもとにまとめました。

## 事故の状況

- 事故310件のうち、火災は272件（約9割）
- 周りの製品や建物にまで被害が広がった事故が181件
- リチウムイオン電池が関係する事故が約3割
- 入手先で多いのは「知人から譲ってもらった製品」、次いでネットのオークションやフリマアプリ

## 使う前の5つのチェック

1. リコールの対象ではないか。中古品はメーカーからの連絡が届きにくい。消費者庁リコール情報サイトなどで検索する
2. 古すぎないか、不具合がないか。破損・変形・異音・異臭があるものは使わない
3. リチウムイオン電池の製品は、膨らみ・異常な発熱・非純正バッテリーでないかを特に確認する
4. 取扱説明書を手に入れる。なければメーカーのサイトで探す
5. 修理・改造されていないか。自分で直した跡のある製品は使わない

NITEが紹介している事故例には、メーカーが無償点検を呼びかけていたのに知らずに使っていた除湿機、40年以上使われたエアコン、はんだ付けで修理された除雪機などがあります。

## 譲る・売る側も

製造年や使っていた期間、不具合の有無、非純正バッテリーかどうかを伝え、取扱説明書（URLでも可）を一緒に渡しましょう。
