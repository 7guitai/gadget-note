# Claude Fable 5.2が登場。Proプランの人は11月17日まで追加料金なしで試せます

Anthropicが11月9日（米国時間）、AIモデル「Claude Fable 5.2」を発表しました。あわせて、有料プランの人向けに期間限定のローンチオファーが始まっています。

Anthropicの公式発表とヘルプセンターをもとに、ポイントをまとめました。

## Fable 5.2ってどんなモデル？

- Anthropicが「最も難しい技術的な課題」向けと位置づけるモデル
- 前のFable 5.1より最大30%速く出力する
- サイバーセキュリティと生物学の分野では、悪用を防ぐ強い安全対策が入っている（同じ土台で安全対策の一部がない「Mythos 5.2」は、審査のあるプログラム経由）

ただし、Anthropic自身は「ほとんどのコーディングや知的作業は、まずClaude Opus 5.5から」とすすめています。Fableは、大きく難しい作業のときに切り替えるモデル、という位置づけです。

## Proプランは「1週間」使える

Proプラン（とTeamプランの標準シート）では、ふだんは追加の使用量クレジットで使うFableモデルが、期間限定でプランの中で使えます。

- 期限：日本時間11月17日（火）午後4時59分まで
- 週間使用量制限の最大50%まで、追加料金なし
- Fable制限リセット1回つき
- デフォルトのモデルは変わらないので、モデルの選択メニューからFableを選ぶ
- Fableはほかのモデルより使用量を速く消費するので、「設定」→「使用量」で残りを確認する

## Max・Ultraプランの人は「リセット」

Max・Ultraプランなどでは、有料で使っている期間に応じて、Fableの使用量を元に戻せる「Fable制限リセット」が1〜3回もらえます（6か月未満1回、6〜12か月2回、12か月以上3回）。「設定」→「使用量」の「制限リセット」から使えます。

なお、Freeプランは今回のオファーの対象外です。

## 試すなら

ふだんの調べものや文章づくりなら、Opus 5.5などで十分なことが多そうです。大きなプログラムの作業など、難しい技術的な作業がある人は、この1週間で試してみるのもよいかもしれません。
