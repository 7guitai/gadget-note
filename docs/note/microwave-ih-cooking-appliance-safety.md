# 電子レンジにアルミホイルは発火の危険。調理家電の事故を防ぐ3つのポイント

火を使わない調理家電でも、使い方を間違えると火災が起きています。NITE（製品評価技術基盤機構）の注意喚起をもとにまとめました。

## 事故の約75%が火災

NITEによると、調理家電の事故は5年間で515件、そのうち388件が火災でした。多いのは電子レンジ（149件）とIHこんろ（92件）。原因がわかった事故では、使い方の誤りや不注意が関係するものが約4割でした。

## 電子レンジで多い「ヒヤリ」

NITEのアンケートで多かったのは、次の使い方です。

- 金属製品をレンジ加熱した（アルミホイル、金・銀の縁の食器、アルミの袋、パン袋の針金など）
- 卵をレンジ加熱した
- 長時間加熱しすぎた

## 事故を防ぐ3つのポイント

1. 加熱のしくみを知る。レンジ加熱（内側から）とグリル・オーブン（ヒーターで外側から）、IHヒーターとラジエントヒーター（鍋がなくても熱くなる）の違い
2. 取扱説明書や食品パッケージの注意を守り、モードとタイマーを確認してから加熱する
3. こまめに掃除し、熱くなる場所に調理器具以外の物を置かない

庫内で煙や火が出たら、ドアを開けないようにしましょう。
