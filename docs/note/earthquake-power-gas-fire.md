# 地震のあと、電気が戻ったときに火事に？「通電火災」を防ぐために覚えておきたいこと

大きな地震のあと、停電から電気が戻ったときに火災が起きることがあります。「通電火災」と呼ばれるものです。

NITE（製品評価技術基盤機構）の注意喚起をもとに、地震のとき、そして電気やガスが戻るときに気をつけたいポイントをまとめました。

## なぜ電気が戻ると火事になるの？

地震の揺れで、こんなことが起きることがあります。

- 家具や家電が倒れて、電源コードが傷ついたり、切れかけたりする
- 電源プラグに強い力がかかって、変形する
- 倒れた電気ストーブに、服や本が触れたままになる

気づかないまま電気が戻ると、そこから発熱・発火するおそれがあります。NITEの資料によると、消防白書では、東日本大震災の火災の半数以上が電気関係とされています。

ガスも、揺れでガス栓と機器の接続がゆるむと、使い始めたときにガスが漏れて引火するおそれがあります。

## 揺れが収まったら（身の安全が最優先）

- ガス機器の火を消す。避難するとき、余裕があればガスの元栓を閉める
- 電気製品のスイッチを切って、プラグを抜く（特に電気ストーブなどの電熱器具）
- 避難するときは、分電盤のブレーカーを切る
- ガスのにおいがしたら、換気扇や電気のスイッチに触れず、窓を開けて換気する

## 電気・ガスが戻るとき

- 電気が戻る前に、ブレーカーが切れているか確認する
- 水に浸かった製品は使わない
- 浸水していない製品も、コードの傷や焦げあとを確認する
- 異常がなければブレーカーを入れて、プラグを1台ずつ差して様子を見る
- ガスは、ソケットがしっかり差し込まれているか、使っていないガス栓を開けていないか確認する

## ふだんからできる備え

- 家具を壁に固定する
- 暖房器具のまわりに燃えやすいものを置かない
- 分電盤とガスの元栓の場所を、家族で確認しておく
- 揺れを感じると自動で電気を止める「感震ブレーカー」を付ける

感震ブレーカーは、自治体によっては設置費用の助成や配布をしているところもあるそうです。住んでいる自治体のホームページを一度のぞいてみてはいかがでしょうか。
