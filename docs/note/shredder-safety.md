# シュレッダーにエアダスターは爆発の危険。紙詰まりのNG対処と3つの注意

大掃除やテレワークで使う家庭用シュレッダー。紙詰まりを直そうとスプレーを吹き付けて爆発したり、指を挟んだりする事故が起きています。NITE（製品評価技術基盤機構）の注意喚起をもとにまとめました。

## どんな事故が起きている？

NITEによると、2018〜2022年度の5年間にシュレッダーの事故は15件、そのうち8件が火災でした。多かったのは次の使い方です。

- 紙詰まりに可燃性ガスを含む潤滑スプレーなどを使い、中にたまったガスに引火して爆発（6件）
- 無理に押し込もうとして、投入口に指を挟んだ（4件）
- 安全装置が働かない状態で使い、刃に指を巻き込んだ（2件）

## 事故を防ぐ3つのポイント

1. 潤滑スプレーやエアダスターなど、可燃性ガスのスプレーを使わない。電池も入れない
2. 投入口に指を近づけない。紙が引き込まれ始めたらすぐ手を離す
3. 扉を開けると刃が止まる安全装置（インターロック）が働くか確認する。紙粉がたまると働かないことがある

紙詰まりは取扱説明書の手順で直し、異音がするときは分解せずメーカーに相談しましょう。
