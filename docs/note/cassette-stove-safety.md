# カセットボンベが破裂する原因は？鍋の季節に気をつけたい3つのこと

鍋や焼肉に便利なカセットこんろ。使い方を間違えると、カセットボンベが熱くなって破裂する事故が起きています。NITE（製品評価技術基盤機構）の注意喚起をもとにまとめました。

## 事故の4割は使い方のミス

NITEによると、カセットこんろの事故は10年間で91件。原因を調べ終えた86件のうち、約4割が誤った使い方や不注意によるものでした。特に多いのが、ボンベが熱くなる使い方をして破裂した事故です。

- こんろを2台並べ、大きな鉄板で調理していてボンベが破裂、6人がやけど
- 燃えているこんろのそばにボンベを置いていて破裂、9人がやけど

## 事故を防ぐ3つのポイント

1. ボンベは無理に押し込まず、説明書どおりの向きで確実にセットする。異音・異臭がしたらすぐ外す
2. 2台並べて使わない。ほかの調理器の上にのせない、炭おこしに使わない
3. 使い終わったらボンベを外し、室内の40℃未満の場所に保管する。ストーブやこたつのそばに置かない

## 古いこんろ・ボンベは

- 見た目に異常がなくても、こんろは10年、ボンベは7年が買い替えの目安
- ボンベは使い切って、振っても音がしなくなってから自治体のルールで捨てる
