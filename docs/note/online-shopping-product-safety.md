# ネット通販の家電、事故の約3割に。「ポチる」前の4つのチェック

ネット通販で買った製品による事故が増えています。NITE（製品評価技術基盤機構）によると、買い方がわかった製品事故のうち、ネットで買った製品の割合は2022年度以降約3割。NITEの注意喚起をもとにまとめました。

## どんな製品で事故が多い？

販売元が海外などで、作った・輸入した事業者がわからなかった事故では、バッテリーが突出して多く（10年で228件、うち火災208件）、照明器具やガストーチが続きます。事業者がわからないと、事故が起きても対応を受けられないおそれがあります。

## 買う前の4つのチェック

1. ほかの製品と比べて極端に安くないか（安全のための試験やコストが省かれているおそれ）
2. 販売元が信頼できるか。不自然な日本語やサクラレビューに注意。国内の連絡先が実在し、日本語で対応できるか
3. PSEなどのマークの近くに事業者名があるか。「PSEマーク取得」という表記にも注意（マークは事業者が自分で表示するもの）
4. リチウムイオン電池の製品は、自治体や量販店で回収してもらえるか、買う前に捨て方を調べる

2025年12月からは、ネットで直接売る海外事業者にも国内の責任者を置くことなどが求められるようになりました。それでも、買う前の確認は続けましょう。
