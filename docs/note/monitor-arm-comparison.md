# モニターアーム、どれを選ぶ？「3軸」「4軸」「2画面」の違いを仕様で比べました

モニターアームを付けると、机の上が広くなって、画面の高さや位置も自由に変えられます。でも、種類が多くて迷いますよね。

同じシリーズで3タイプがそろっている、グリーンハウスのガススプリング式モニターアーム（GH-AMCA01・02・03）の公式仕様をもとに、違いを整理しました。メーカーの公表仕様をもとにした比較で、実機での検証はしていません。

## 3タイプの違い

- GH-AMCA01（3軸・1画面）：画面の高さと左右を調整できる。本体の奥行き431mm、約3.5kg
- GH-AMCA02（4軸・1画面）：前後・左右・上下に動かせる。本体の奥行き651mm、約3.9kg
- GH-AMCA03（4軸・2画面）：2台のモニターをそれぞれ動かせる。1本あたり9.0kg・合計18.0kgまで、約6.2kg

3つとも、ネジ穴（VESA）は75mm・100mm、モニターは27インチまで、C型クランプで机に固定するタイプです。

## 選び方の順番

- モニターは27インチまで、スタンドを除いて9.0kg以下？
- 2台付けたいなら → GH-AMCA03
- 1台で、画面を手前や奥にも動かしたいなら → GH-AMCA02
- 高さと左右が変えられればよいなら → GH-AMCA01

## 机の側も確認しておきたいこと

- 天板の厚さ：1台用は10〜90mm、2台用は10〜80mm
- 天板の奥行き：1台用は110mm以上、2台用は120mm以上
- 天板の裏の板（バックパネルなど）とぶつからないか
- 4軸タイプは本体の奥行きが長いので、机の奥や壁との距離に余裕があるか

買ってから「付かなかった」とならないよう、モニターと机のサイズを先に測っておくのがおすすめです。
