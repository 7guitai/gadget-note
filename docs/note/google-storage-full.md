# 「Googleの保存容量がもうすぐいっぱいです」と言われたら。まずやることと、放っておくと困ること

Gmailやスマホの写真を使っていると、ある日「保存容量がいっぱい」という通知が届くことがあります。Googleアカウントの無料の保存容量15GBは、Gmail・Googleドライブ・Googleフォトで共有されているからです。

Googleのヘルプをもとに、対処の順番をまとめました。

## いっぱいになると何が困る？

- Gmailでメールの送受信ができなくなることがある
- Googleドライブにファイルをアップロードできない
- Googleフォトに写真をバックアップできない

さらに、上限を超えたまま2年以上たつと、Gmail・フォト・ドライブのデータが削除されることがあります（3か月以上前に通知があります）。

## まずはゴミ箱と迷惑メール

いちばん早いのは、Gmail・ドライブ・フォトのゴミ箱と、Gmailの迷惑メールを空にすることです。ここにあるものも、完全に消すまでは容量に数えられています。

消したあと、空き容量に反映されるまで最長で48〜72時間かかることがあります。

## 大きなものを探す

- Gmail：検索バーに「has:attachment larger:10M」と入れると、10MBを超える添付ファイル付きのメールが見つかる
- ドライブ：左のメニューの「ストレージ」で、サイズの大きい順に並ぶ
- 使っていない古いスマホのバックアップも確認する

2021年6月より前に「保存容量の節約画質（以前の高画質）」で保存した写真は、もともと容量に数えられていないので、消しても空きは増えません。

## それでも足りないとき

Google Oneで保存容量を追加できます。追加した容量は、Gmail・ドライブ・フォトで共有されます。

消す前には、大事な写真やファイルが別の場所に残っているか、一度確認しておきましょう。
