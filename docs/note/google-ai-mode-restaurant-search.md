# Google検索のAIモードで、レストランの空席を探せるようになりました

2026年11月6日、Googleが、Google検索の「AIモード」で、レストランの予約検索機能の提供を始めました。

「金曜の夜、4人で、渋谷あたりのイタリアン」のように条件をまとめて伝えると、空席のあるお店を探してくれる、という機能です。Googleの公式ブログの内容をまとめました。

## どんな機能？

- 人数・日時・場所・料理のジャンルなど、複数の条件や好みをまとめて伝える
- AIモードが、複数の予約サイトやウェブサイトを横断して検索
- 条件に合うお店の空席状況を、リアルタイムで確認
- 予約できる枠があるお店を、一覧にしてくれる

日本では、ぐるなび、一休、ebica などと協力して提供するそうです。

## 予約は自分で完了させる

ここが大事なポイントで、AIモードが予約を確定してくれるわけではありません。一覧から気になるお店の予約ページへのリンクを開き、そこで自分で予約を完了させる仕組みです。

人数・日時・料金・キャンセル規定などは、AIのまとめではなく、予約サイトの画面で確認してから確定しましょう。

## すぐには使えないかも

Googleは「今後数週間かけて順次」使えるようになるとしています。まだ表示されなくても、しばらく待ってみてください。

## AIモードってどこにあるの？

AIモードは、Google検索の結果ページに表示される「AIモード」タブから使えます。パソコンやスマホのブラウザ、AndroidとiOSのGoogleアプリで使えます。日本語では2025年9月から提供されています。

声で質問したり、写真を撮って質問したりもできます。

ただ、Google自身も「常に完璧というわけにはいかない」としているので、お店の営業時間や場所などは、公式の情報で確かめるのが安心です。
