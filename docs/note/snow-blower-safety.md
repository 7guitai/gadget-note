# 除雪機の事故は12月に一番多い。使い始める前に家族で確認したい5つのこと

雪の多い地域では、そろそろ除雪機の出番ですね。実は除雪機の事故は、シーズンが始まる12月に最も多く起きています。

NITE（製品評価技術基盤機構）の注意喚起をもとに、気をつけたいポイントをまとめました。

## 事故の9割以上が死亡や重傷に

NITEによると、2015年度から2024年度までの10年間に、除雪機で人がけがをしたり亡くなったりした事故は38件。

- そのうち36件が、死亡や重傷を伴う重大な事故
- 約8割が、誤使用や不注意によるもの
- 12月が最も多く、シーズン前の試運転で事故にあった例も
- 被害者の多くが高齢者

「下敷きになった」「回転部に巻き込まれた」事故で、亡くなった方が多くなっています。

## 使う前に確認したい5つのこと

1. 安全機能を無効化しない
2. 後ろに下がるときは、足元と後ろを確認する
3. 近くに人がいるときは使わない。エンジンをかけたまま離れない
4. 雪詰まりは、エンジンを切って雪かき棒で取る
5. 屋内や換気の悪い場所では、エンジンをかけたままにしない

## 「デッドマンクラッチ」は外さないで

歩いて操作するタイプの除雪機には、レバーから手を離すと回転部と走行が自動で止まる「デッドマンクラッチ」という安全機能があります。

NITEの事故例では、このレバーを洗濯ばさみで固定して安全機能を無効にし、回転部に巻き込まれて亡くなった事故が紹介されています。面倒でも、安全機能は絶対に無効にしないでください。

## 子どもと一酸化炭素にも注意

- 背の低い子どもは死角に入りやすいので、周りに人がいないか確認する
- 排気には一酸化炭素が多く含まれる。色もにおいもないので、風通しの良い屋外で使う

NITEは、使う人本人だけでなく、離れて暮らす家族や周りの人のサポートや声かけもお願いしたいとしています。実家で除雪機を使っている人は、この冬が始まる前に一度話してみてはいかがでしょうか。
