# はしごの角度は75度。脚立にまたがるのはNG

大掃除や高い所の作業で使う、はしごと脚立。使い方を間違えて転落し、骨折する事故が起きています。NITE（製品評価技術基盤機構）の注意喚起をもとにまとめました。

## 事故の約4割が60歳代以上

NITEによると、はしご・脚立の事故は5年間で162件。年代がわかった事故の約4割が60歳代以上で、ほとんどが転落、半数近くが重傷でした。原因の半数近くは、使い方の誤りや不注意です。

## はしごの注意

- はしごは昇り降りだけに使い、乗ったまま作業しない
- 立て掛ける角度は約75度。側面の「角度指示ラベル」を参考に
- 下を誰かにしっかり支えてもらう

## 脚立の注意

- 天板に乗ることが禁止されている脚立では、天板に乗らない・座らない
- 天板にまたがらない
- 脚立の上で壁や物を強く押したり引いたりしない。横に体を乗り出さない

## 共通の注意と選び方

- 開き止め具を確実にロックし、平らでかたい地面に置く
- アウトリガー（補助脚）付きはしごや、手すりになる上枠付き脚立など、安全機能の付いた製品もある
- JIS・SG・Aマークも選ぶときの目安に
