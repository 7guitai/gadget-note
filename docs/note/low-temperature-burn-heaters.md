# 「温かいだけ」でもやけどに。電気あんか・カイロ・電気マットの低温やけどに気をつけて

寒くなってくると、電気あんかやカイロ、電気マットが手放せなくなりますよね。ストーブよりやさしい温かさですが、使い方によっては「低温やけど」になることがあります。

NITE（製品評価技術基盤機構）の注意喚起（2025年1月）をもとにまとめました。

## 低温やけどの目安

温かいと感じる程度でも、同じところに長く触れていると、皮膚の深いところまでやけどすることがあります。

- 44℃：3〜4時間
- 46℃：30分〜1時間
- 50℃：2〜3分

（NITEが引用する製品安全協会の資料の目安。個人差があり、44℃以下でもなることがあります）

高齢の人は熱さに気づきにくく、重くなりやすいそうです。

## 電気あんか

- 寝る前に布団を温めたら、スイッチを切るか、体から十分に離す
- タオルで包んでも、低温やけどのおそれはある
- コードを無理に曲げたり、本体に巻きつけたりしない

## カイロ

- 直接肌にあてない
- 寝るときは使わない（布団の中で熱がこもる）
- 同じところに長くあてない、押さえつけない
- こたつの中や暖房器具の近くで使わない

## 電気マット

- 布団の中に入れて、寝るときの暖房にしない
- 折り曲げたり、しわが寄ったまま使ったりしない
- 重いものを載せない、針を刺さない

実家の家族にも、寝るときの使い方を一度聞いてみると安心です。
