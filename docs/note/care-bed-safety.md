# 介護ベッドの「すき間」、確認していますか？家族で見直したい事故防止のポイント

親の介護などで、家に介護ベッドを置いている人も多いと思います。実は介護ベッドの事故は、手すりとマットレスのすき間などに体が挟まるものが半数以上を占めています。

NITE（製品評価技術基盤機構）の注意喚起をもとに、介護ベッドと電動車いすの事故を防ぐポイントをまとめました。

## ほぼ毎年、死亡事故が起きている

NITEによると、2016年から2025年までの10年間に、高齢者が被害にあった事故は、介護ベッドで43件、電動車いすで59件。どちらも、ほぼ毎年死亡事故が起きています。

- 介護ベッド：すき間に挟まる事故が23件で最も多い
- 電動車いす：側溝や川などへの転落が26件、踏切で電車と接触が13件

使う前の確認や、周りの見守りで防げる可能性がある事故も多いそうです。

## 介護ベッドで確認したいこと

- JIS規格に適合した製品か。JIS規格は2009年にすき間の決まりが見直されていて、それより前の製品には合っていないものもある
- 頭や首、手足が入りそうなすき間がないか
- すき間があれば、スペーサーや保護カバーでふさぐ
- リクライニングを動かす前に、手足がすき間に入っていないか

新しく入れるときは、JISマーク付きの製品を選びましょう。

## 電動車いすで確認したいこと

- 使う道路を、家族や介助者と一緒に確認する（踏切や、ふたのない側溝、急な坂は避ける）
- 乗る前に、バッテリーの残量を確認する
- 乗る前の点検と、取扱店などでの定期点検

NITEは、使う本人だけでなく、家族や介助者も一緒に確認してほしいと呼びかけています。帰省したときなどに、一度ベッドまわりを見てみてはいかがでしょうか。
