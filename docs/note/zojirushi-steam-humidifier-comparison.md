# 象印のスチーム式加湿器、どれを選ぶ？4シリーズを仕様で比べました

フィルターがなく、お手入れが簡単な象印のスチーム式加湿器。2026年9月発売の4シリーズを、メーカー公式の仕様をもとに比べました。実機での検証はしていません。

## 部屋の広さで選ぶ目安（プレハブ洋室）

- EE-MC20：〜6畳。幅20cm・2.0kgのコンパクトタイプ。寝室向け
- EE-RV35／EE-RV50：〜10畳／〜13畳。基本機能に絞ったベーシックタイプ
- EE-DG35／EE-DG50：〜10畳／〜13畳。「弱」で約32時間の長時間加湿
- EE-TC60：〜17畳。加湿量600mL/hで広いリビング向け

## 共通の特徴

- 水を沸とうさせ、約65℃まで冷ましてから蒸気を出す
- チャイルドロック、ふた開閉ロック、転倒湯もれ防止構造
- フィルターがなく、広口容器を拭くだけでお手入れできる

## 買う前に確認したいこと

- スチーム式は消費電力が大きめ（湯沸かし時985W、MC20は650W）
- 約65℃でも、蒸気の吹き出し口には触れない。子どもの手が届かない場所に置く
- 季節限定品で、品切れになることもある
