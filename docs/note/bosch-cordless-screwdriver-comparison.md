# 家具の組み立て用の電動ドライバー、どれを選ぶ？ボッシュの4機種を仕様で比べました

組み立て家具のネジ締め、手回しだと疲れますよね。ボッシュの家庭用コードレスドライバー4機種を、メーカー公式の仕様をもとに比べました。実機での検証はしていません。

## 目安

- 家具の組み立てやちょっとした修理が中心なら、3.6Vの小型ドライバー
- 下穴あけや固い木材へのネジ締めもしたいなら、18Vのドリルドライバー

## 4機種の特徴

- IXO 7：3.6Vの中でトルク（最大5.5N・m）と電池容量（2.0Ah）が大きめ。1回の充電で最大190本分のネジ締めとしている。六角ビット（HEX 3・HEX 5）を含むビット10本付き
- PushDrive：本体を押し込むと回る。0.28kgと最も軽く、トルクを6段階に調整できる。ビット32本付き
- EasyScrewDrive：基本のネジ締めに絞ったシンプルな機種。ビット5個付き
- EasyDrill 18V-40：18Vのドリルドライバー。最大32N・m、2段変速と20段階のトルク調整。重さは1.30kg

## 買う前に確認したいこと

- 3.6Vの3機種はネジ径最大5mm。家具のネジのサイズを確認する
- 3.6Vの3機種の充電はMicro-USB（USB-Cではない）
- 18Vのバッテリーを買い足すときは、非純正品に注意する
