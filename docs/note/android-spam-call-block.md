# 知らない番号からの電話が多いときに。Androidの「電話」アプリでできる迷惑電話対策

知らない番号からの電話、出るべきか迷いますよね。Androidスマホの「電話」アプリ（Google製）には、迷惑電話を減らすための機能がいくつかあります。

Googleの電話アプリ ヘルプをもとにまとめました。なお、メーカー独自の電話アプリを使っている場合は、画面や手順が違います。

## 1. 迷惑電話の警告（最初からオン）

連絡先にない番号からの着信で、お店の名前を表示したり、「迷惑電話の疑いあり」と警告したりします。

- 場所：電話アプリ → 設定 → 発信者番号 / 迷惑電話
- 連絡先にない番号との通話では、その番号がGoogleに送られて判断に使われます（連絡先リストは取得しないと説明されています）

## 2. 迷惑電話をフィルタ

同じ画面の「スパムの疑いがある通話をフィルタ」をオンにすると、迷惑電話の疑いがある着信が鳴らなくなります。

- 通知は来ないけれど、通話履歴には残る
- 知り合いの電話が誤って判定されていたら「スパムではない」で報告できる

## 3. 番号をブロック

- 通話履歴から番号を選んで「ブロック / 迷惑電話を報告」
- 非通知などは、設定の「ブロック中の電話番号」で「不明」をオン

## 4. Pixelの「詐欺検知」

Pixel 9以降（日本）では、通話中に詐欺の疑いがある会話を見つけて警告してくれる「詐欺検知」があります。

- 最初はオフ。設定 → 詐欺検知 でオン
- 処理は端末の中で行われ、会話は保存・送信されないと説明されています
- ただし精度は100%ではないので、知らない番号には慎重に
