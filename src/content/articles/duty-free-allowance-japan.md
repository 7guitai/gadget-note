海外旅行のお土産は、1人あたり**お酒3本（1本760ml）**、**紙巻たばこ200本**、**香水2オンス**、そして**その他の品物は海外での価格の合計20万円まで**なら、税金がかかりません（免税）。20歳未満の人は、お酒とたばこは免税になりません。

この記事では、税関の「海外旅行者の免税範囲」「税額の計算方法」などのページをもとに、免税範囲の数え方、超えた場合の税金、入国時の申告を整理します。

## 免税範囲（1人あたり）

税関の案内では、個人で使うと認められるものに限り、入国者1人あたり次の範囲で免税になります。

| 品名 | 免税になる数量・価格 | 備考（税関の案内より） |
|---|---|---|
| お酒 | 3本 | 1本760mlとして数える |
| たばこ（紙巻たばこだけの場合） | 200本 | |
| たばこ（加熱式たばこだけの場合） | 個装など10個 | 1箱あたり紙巻たばこ20本に相当する量 |
| たばこ（葉巻たばこだけの場合） | 50本 | |
| 香水 | 2オンス | 1オンスは約28ml。オーデコロン、オードトワレは含まない |
| その他の品物 | 20万円 | 海外での価格の合計額 |

ほかにも、次の決まりがあります。

- **20歳未満**は、お酒とたばこは免税にならない
- **6歳未満の子ども**は、おもちゃなど、明らかに本人が使うもの以外は免税にならない
- 旅行先から送った荷物（**別送品**）がある場合は、手荷物と合わせて数える（入国後6か月以内に輸入するものに限る）

## 「20万円」の数え方

その他の品物の20万円は、少し数え方に注意が必要です。

- **1個で20万円を超える品物は、全額が課税**される。たとえば、25万円のバッグは、25万円の全額に税金がかかる
- 合計が20万円を超える場合は、20万円以内に収まる品物が免税になり、残りに税金がかかる。税関は、**旅行者に有利になるように**免税にする品物を選ぶ
- **1品目ごとの海外での価格の合計が1万円以下**のものは、原則として免税。税関の例では、1個1,000円のチョコレート9個や、1本5,000円のネクタイ2本は免税になる

「海外での価格」は、外国での通常の小売価格です。円への換算は、決められた公示レートで行われます。

## 免税範囲を超えたときの税金

税関の「税額の計算方法」によると、お土産などの場合は、**海外での購入価格に0.6をかけた額**を課税価格として、税率をかけて計算します。お土産によく使われる「簡易な税率」の例は次のとおりです。

| 品物 | 税率（税関の案内より） |
|---|---|
| ウイスキー、ブランデー | 1リットルあたり800円 |
| ラム、ジン、ウォッカ | 1リットルあたり500円 |
| リキュール | 1リットルあたり400円 |
| 焼酎 | 1リットルあたり300円 |
| その他のお酒（ワイン、ビールなど） | 1リットルあたり200円 |
| 紙巻たばこ | 1本あたり15円 |
| その他の品物（関税がかからない物を除く） | 15% |

たとえば、税関の計算例では、免税範囲を超えた**ブランデー1本（700ml）**には、0.7リットル×800円＝**560円**がかかります。また、衣類5万円の場合は、5万円×0.6＝3万円に15%をかけて**4,500円**です。

腕時計やパソコンなど関税がかからない品物は、消費税と地方消費税（合計10%、軽減税率の対象は8%）だけがかかります。また、1個（1組）の課税価格が10万円を超えるものなど、簡易な税率を使えない品物もあります。

## 入国時の申告

日本に入国（帰国）するときは、**全員が「携帯品・別送品申告書」を提出**します。免税範囲内でも提出が必要です。

税関は、デジタル庁の「**Visit Japan Web**」での電子申告を勧めています。Visit Japan Webにログインして申告の内容を入力すると、二次元コードが表示されます。空港に着いたら、税関検査場の電子申告端末で二次元コードとパスポートを読み取ると、**電子申告ゲート**を使えます（税関職員の検査を受ける場合もあります）。紙の申告書は、空港や港の税関に置いてあるほか、税関のサイトから印刷することもできます。

旅行先から荷物を送った（別送品がある）場合は、税関の「別送品手続」の案内もあわせて確認しましょう。
