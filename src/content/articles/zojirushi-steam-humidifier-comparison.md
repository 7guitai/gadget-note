象印のスチーム式加湿器は、**部屋の広さ**と**1回の給水で何時間使いたいか**で選ぶのが目安です。2026年9月に発売された4シリーズを、メーカー公式ページの仕様で比べると、次のように分けられます。

- **EE-TC60**：プレハブ洋室〜17畳。広いリビング向けで、加湿量がいちばん多い
- **EE-DG35／EE-DG50**：〜10畳／〜13畳。「弱」で約32時間の長時間加湿
- **EE-RV35／EE-RV50**：〜10畳／〜13畳。基本機能に絞ったベーシックタイプ
- **EE-MC20**：〜6畳。寝室などに置くコンパクトタイプ

メーカーの公表仕様をもとにした比較で、実機での検証はしていません。価格は販売店によって違うため、この記事には書いていません。

## 先に確認すること：スチーム式の特徴

スチーム式は、**水をヒーターで沸とうさせて、蒸気で加湿する**方式です。象印の製品は、**フィルターがないポットのような構造**で、広口の容器を拭くだけで手入れできるとしています。沸とうさせた蒸気を、ふたの上の空間で室温の空気と混ぜて**約65℃まで冷まして**から出す「スチーム冷却構造」も特徴です。

一方で、水を温めるぶん、**消費電力は大きめ**です。今回の4シリーズでは、湯沸かしの立ち上げ時に**985W**（EE-MC20は650W）、加湿中に**190〜450W**ほどかかります。また、約65℃に冷ましていても、**蒸気の吹き出し口には触れない**ように、とメーカーも注意しています。

スチーム式の熱い蒸気やお湯によるやけどの注意は、<a href="/articles/humidifier-safety/">加湿器の蒸気は90℃超えも｜子どものやけど・水あかの発火を防ぐ5つの注意</a>で紹介しています。

## 4シリーズの仕様の比較

以下は、象印公式サイトの仕様の値です（2026年11月24日確認）。適用床面積は、日本電機工業会の規格（JEM1426）に基づく目安です。

| | EE-TC60 | EE-DG35 / DG50 | EE-RV35 / RV50 | EE-MC20 |
|---|---|---|---|---|
| 適用床面積（プレハブ洋室） | 〜17畳 | 〜10畳 / 〜13畳 | 〜10畳 / 〜13畳 | 〜6畳 |
| 適用床面積（木造和室） | 〜10畳 | 〜6畳 / 〜8畳 | 〜6畳 / 〜8畳 | 〜3畳 |
| 定格加湿能力 | 600mL/h | 350 / 480mL/h | 350 / 480mL/h | 200mL/h |
| 容量（タンク） | 4.0L | 3.0 / 4.0L | 2.2 / 3.0L | 1.8L |
| 連続加湿時間 | 強6／中10／弱20時間 | 強8／中16／弱32時間 | 強6／弱27・24時間 | 標準8／静音16時間 |
| 消費電力（湯沸かし立ち上げ時） | 985W | 985W | 985W | 650W |
| 消費電力（加湿時） | 450W | 305 / 410W | 305 / 410W | 190W（静音134W） |
| 加湿時の運転音 | 強・中34／弱30dB | 29 / 30dB | 32 / 34dB | 標準32／静音30dB |
| 本体質量 | 2.8kg | 2.7 / 2.9kg | 2.3 / 2.4kg | 2.0kg |
| 外形寸法（幅×奥行×高さ） | 24×27.5×36.5cm | 24×27.5×32.5 / 36.5cm | 24×26×27.5 / 31.5cm | 20×23×26.5cm |

連続加湿時間は、メーカーの条件（室温20℃、満水時など）での値です。運転音は加湿時の値で、**湯沸かし時はもう少し大きく**なります（EE-DGシリーズの公式ページでは、加湿時約30dB、湯沸かし時約39dBと案内）。

## 4シリーズ共通の安全機能

公式ページでは、4シリーズすべてに次の機能があると案内されています。

- **チャイルドロック**：キーを3秒以上長押しすると、すべての操作ができなくなる（安全のため「切」キーでは停止できる）
- **ふた開閉ロック**：レバーでふたを常にロックし、倒れても簡単に開かない
- **転倒湯もれ防止構造**：倒れても、お湯のもれを最小限に抑える（ふたがしっかり閉まっていることが前提。倒れたまま放置すると、蒸気口から少しお湯が出る）

あわせて、手入れには**クエン酸洗浄モード**が案内されています。

## 広いリビングならEE-TC60

**プレハブ洋室〜17畳**まで対応し、加湿量は4シリーズでいちばん多い**600mL/h**です。タンクは4.0L。

- **湿度センサーと室温センサー**で湿度を自動で調整する「自動加湿3段階」
- 湯沸かしの音を抑える「**湯沸かし音セーブモード**」（湯沸かしにかかる時間は長くなる）
- 加湿時の消費電力は450Wと、4シリーズでいちばん大きい

## 一晩じゅう給水なしで使いたいならEE-DG35／EE-DG50

「弱」で**約32時間**、「強」でも約8時間の連続加湿ができる**長時間加湿タイプ**です。EE-DG50はタンク4.0Lで〜13畳、EE-DG35は3.0Lで〜10畳。

- 加湿時の運転音は**約29dB（DG35）／約30dB（DG50）**で、4シリーズの中では低め
- 自動加湿3段階、湯沸かし音セーブモード付き

寝室とリビングの両方で使う、給水の回数を減らしたい人に向きます。

## 基本機能でよければEE-RV35／EE-RV50

公式ページで「**ベーシックタイプ**」とされているシリーズです。対応する部屋の広さと加湿能力はEE-DGと同じですが、**タンクが一回り小さく**（2.2L／3.0L）、連続加湿時間は「強」で約6時間です。

- 自動加湿3段階、湯沸かし音セーブモード付き
- 4シリーズの中で、EE-MC20の次に軽い（2.3／2.4kg）

## 寝室や一人暮らしの部屋ならEE-MC20

**プレハブ洋室〜6畳**向けのコンパクトタイプです。幅20cm・2.0kgと4シリーズでいちばん小さく軽く、消費電力も立ち上げ時650W、加湿時190W（静音モード134W）と控えめです。

- 「標準」と「静音」の2つのモード。運転音は約32／30dB
- 2時間後か4時間後に切れる**切タイマー**
- 公式ページでは、湯沸かし音セーブモードや自動加湿3段階の案内は確認できませんでした

## 購入前に確認したいこと

- **季節限定品**：象印は、加湿器を季節限定品としていて、品切れの場合があるとしています
- **電気代**：スチーム式は水を温めるため、ほかの方式より消費電力が大きくなりがちです。使う時間が長い場合は、消費電力の数字も比べましょう
- **置き場所**：子どもの手が届かない、倒れにくい平らな場所に置き、電源コードに引っかからないようにします
- **アロマは使わない**：取扱説明書で使えると書かれていないものは、タンクに入れないでください
