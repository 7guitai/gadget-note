Googleは**2026年11月2日**、XREALと共同で、Android XRを搭載した初の有線XRグラス「**XREAL AURA（エックスリアル オーラ）**」を発表しました。日本では同じ日から**予約受付が始まり**、出荷は**11月中旬から順次**の予定です。

AURAは、透明なレンズ越しに現実の景色を見ながら、目の前にアプリや動画の画面を浮かべて使うメガネ型の機器です。**GoogleのAI「Gemini」に話しかけて操作を手伝ってもらえる**のが特徴です。この記事では、Googleの公式ブログとXREALの公式ページをもとに、できること、主な仕様、買う前に確認したいことを整理します。

## XREAL AURAでできること

Googleの発表によると、主な使い方は次の3つです。

| 使い方 | 内容（Googleの発表より） |
|---|---|
| 仕事 | ブラウザや書類、音楽アプリなど複数のアプリを同時に開き、好きな大きさで並べる。Bluetoothのキーボードやマウスもつなげる |
| パソコンの画面を映す | 映像出力に対応したUSB-Cケーブルでノートパソコンをつなぐと、パソコンの画面が1つのウィンドウとして表示される（専用ソフトは不要） |
| 動画・ゲーム | YouTubeやGoogle TVなどを大きな画面で見る。レンズを暗くして映像に集中できる。Google Playのゲームや、携帯ゲーム機・PCの画面も映せる |

画面は**つけている本人にしか見えない**ため、外出先でも書類を開きやすいとGoogleは説明しています。また、移動中は画面が視界の端に小さく収まり、足元や進む方向が見えるようにするとしています。

## Geminiでできること

AURAのAndroid XRには、Geminiが搭載されています。Googleによると、Geminiは**目の前の現実の景色と、画面に表示されているものの両方**から、見ているものや作業の内容を理解します。

- 自然に話しかけて、複数のアプリをまたいだ手伝いを頼める
- 散らかったウィンドウの整理を頼んだり、見ている画面の内容について相談したりできる
- 見ている視界を共有すると、現実の空間や画面の上で**どこを見ればよいかをハイライトで示す**（発表日から使える機能としています）
- ゲームで行き詰まったときに、コントローラーを置かずに声で相談できる

## 主な仕様

XREALの公式ページに書かれている主な仕様は次のとおりです。

| 項目 | 内容（XREAL公式ページより） |
|---|---|
| グラスの重さ | 95g |
| 視野角 | 70° |
| ディスプレイ | ソニー製マイクロOLED、片目1920×1200、最大120Hz、最大1050nits |
| 処理をする本体（コンピューティングパック） | Snapdragon Reality Elite、Android XR |
| メモリ／ストレージ | 16GB／512GB、または12GB／256GB |
| バッテリー（コンピューティングパック） | 4,455mAh（34.84Wh） |
| 目の幅（IPD）のサイズ | Mサイズ 60〜66mm、Lサイズ 66〜72mm |
| その他 | Boseがチューニングしたオーディオ、度付きレンズに対応 |

グラス本体が軽いのは、重い処理をケーブルでつながった**コンピューティングパック**が担うためです。バッテリーもこのパックに入っています。

## 価格と予約

Googleの発表では、**今年末までの発売記念価格として199,900円（税込）から**とされています（2026年11月2日確認）。注文はXREAL AURAの公式ページで受け付けています。メモリとストレージの組み合わせごとの価格は、公式ページで確認してください。

## 買う前に確認したいこと

- **18歳以上が対象**：Googleの発表では、18歳以上のユーザーが対象です。初期設定と、対応するアカウントが必要です
- **使える国**：注記では、米国、カナダ、日本、韓国で使えるとしています
- **目の幅（IPD）のサイズ**：MとLの2サイズがあり、合ったサイズを選ぶと画面のぼやけやゆがみを防げるとXREALは説明しています。自分の目の幅を確認してから選びましょう
- **パソコンとつなぐケーブル**：パソコンの画面を映すには、**映像出力に対応したUSB-Cケーブル**と、パソコン側のUSB-C端子の映像出力対応が必要です。充電専用のケーブルでは映りません。見分け方は<a href="/articles/usb-c-cable-identification/">充電専用ケーブルの見分け方｜USB-Cの転送速度・映像対応も確認</a>で、映像出力に対応したケーブルの例は<a href="/articles/usb-c-cable-240w-comparison/">240W対応のUSB-Cケーブルを比較｜充電だけ・高耐久・映像出力も</a>で紹介しています
- **バッテリーで使える時間**：XREALの公式ページで確認できたのはバッテリー容量で、使える時間はこの記事を書いた時点では確認できませんでした
