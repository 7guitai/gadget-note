Metaは2026年10月12日（現地時間）、新しいAIモデル「Muse Wonder」と、その上位版「Muse Wonder Full」を発表した。Metaは、個人の用事から仕事まで、AIが自分で手順を進める「エージェント」としての作業で最先端の性能を出すモデルだと説明している。この記事では、Metaの公式発表をもとに、何ができるのか、今どこで使えるのか、日本の利用者が気をつけたい点を整理する。

## 何が発表されたか

発表されたのは2つのモデルだ。

| モデル | 位置づけ | 発表時点の提供先 |
| --- | --- | --- |
| Muse Wonder | 新しい主力モデル | Meta Model API（開発者向け）、Muse Code |
| Muse Wonder Full | より大きな上位版 | Muse Codeの有料会員 |

Metaは、両モデルを「最も高性能なモデル」と位置づけている。報道によると、Metaの研究組織が開発した初めての最先端（フロンティア）モデルで、先に公開された軽量モデル「Muse Spark」より大きく、コーディングなどの複雑な作業を得意とする。

APIの料金は、報道によると100万入力トークンあたり4ドル、100万出力トークンあたり20ドル。Muse Wonder FullはAPIでは提供されず、Muse Codeの契約者向けとされている。

## 特徴は「覚えておく」と「やり抜く」

Metaが強調する機能は2つある。

- **Active Memory（アクティブメモリー）**：会話をまたいで利用者に関する情報を保ち、今の作業に関係する内容を取り出して使う。
- **Active Focus（アクティブフォーカス）**：難しい目標に対して、別のやり方を試したり、行き詰まりに対処したり、新しい情報に合わせて進め方を変えたりしながら作業を続ける。重要な操作の前には利用者に確認する。

発表では、ランニングコースの計画、写真をもとにしたオリジナルグッズの注文、結婚式の席次表づくりといった使用例が紹介された。Metaは、ブラウザ上や複数のアプリをまたいで作業できると説明している。

性能については、エージェント・記憶・コーディングの評価で最先端の結果を出したとしているが、公式ブログには具体的な点数が載っておらず、別の報告書を参照する形だ。いずれもMeta自身による評価で、第三者による検証はこれからになる。

## 今使えるもの・これからのもの

発表時点で使えるものと、予定として示されたものは分けて読む必要がある。

| 発表時点で利用可能 | 予定として示されたもの |
| --- | --- |
| Meta Model APIでのMuse Wonder | Museアプリ（muse.ai）でのMuse Wonderの利用。まず有料会員から順に展開 |
| Muse CodeでのMuse Wonder／Muse Wonder Full | 成果物の生成など、より高度な処理への活用 |
| | 安全性に関する詳しい報告書の公開 |

一般の人が使うチャットアプリで体験できるのは、Museアプリへの展開後になる。展開の具体的な日程は、公式発表では示されていない。

## 日本の利用者が気をつけたい点

2026年10月12日時点で、確認した公式発表には、日本での提供状況、対象の国・地域、日本語への対応範囲が書かれていない。英語圏の報道でも日本についての言及は見当たらなかった。APIやMuse Codeを日本から契約できるかは、申し込み画面や公式の案内で確認してほしい。

Active Memoryは、会話をまたいで利用者の情報を保つ機能だ。便利な一方で、何を覚えさせるかは利用者側でも意識したい。Metaは、個人情報の扱いに配慮するよう訓練したと説明しているが、記憶の確認・削除の方法などは、使い始める前にアプリの設定や案内で確かめておくと安心だ。
